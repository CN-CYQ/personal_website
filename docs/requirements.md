# 需求基线

## 产品定位

该项目是长期维护的个人网站，包含公开内容展示和个人管理工具两个方向。
首期只搭建架构与基础约定，不一次性实现全部业务功能。

## 用户角色

- 访客：浏览公开作品、博客和其他公开内容。
- 管理员：维护博客、笔记、作品、日历、音乐及站点配置。

首期只设计单管理员模式。多用户、评论审核和第三方登录暂不纳入基础架构。

## 功能模块

- 个人作品：项目展示、封面、标签、链接和详情。
- 博客与笔记：Markdown 编辑、草稿、发布状态和版本记录。
- 日历：个人事件、提醒和公开日程。
- 天气：指定城市天气、预报和缓存。
- 数据看板：站点访问、内容数量和外部指标聚合。
- 音乐：自有音频文件、播放列表、歌词和播放记录。
- 系统管理：登录、配置、文件上传和健康检查。

## 非功能要求

- 前后端代码、构建、测试和部署互相独立。
- 支持桌面端与移动端。
- 核心页面可访问，支持键盘操作和减少动态效果偏好。
- 第三方密钥只保存在后端。
- 数据迁移可追踪，数据库结构使用 Flyway 管理。
- 高级动效不能阻塞首屏，应支持降级与资源销毁。
